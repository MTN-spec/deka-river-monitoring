# Deka River Environmental Monitoring Platform
## User Interface Walkthrough & Operation Manual

This document details the user interactions and operational interface components of the platform, suitable for the "User Interface & System Operation" section of a degree project write-up.

### 1. Authentication & Entry
The platform is secured by a login portal (`login.html`) utilizing a modern glassmorphism aesthetic over a deep radial gradient. This prevents unauthorized access to the sensitive analytical engines and Earth Engine quota limits.

### 2. The Interactive Map Environment
The central component of the main dashboard (`index.html`) is a responsive Leaflet.js map layer.
- **Watershed Demarcation**: The exact hydrological boundaries of the Deka River Catchment are drawn via GeoJSON polygons, bounding the analytical area.
- **Base Layers**: Users toggle between high-resolution Satellite imagery and Topographic views using the floating glass-panel controls.
- **Point Analysis Operation**: The user can click anywhere within the watershed boundary. A pin drops at the clicked coordinate, and the entire right-side analytics panel shifts from a global "ROI-1" view to a micro-level "Point Analysis: [Lat, Lng]" view.

### 3. Analytics & Diagnostics Sidebar
The right panel serves as the visual readout for the 8-Layer Hybrid Model.

#### Water Quality Index (WQI) Gauge
A dynamic SVG circular gauge indicating the overall health of the river. 
- Automatically shifts colors based on severity (Green = Excellent, Yellow = Fair, Red = Critical).
- Displays the 95% Confidence Interval generated by the Bayesian fusion layer, showing the statistical certainty of the measurement.

#### Model Intelligence Diagnostics
Academic transparency is achieved via the "Model Intelligence" checklist. Unlike standard "black box" AI models, this panel explicitly shows the individual output "votes" of:
1. Physics Engine
2. ML Ensemble
3. CNN + LSTM
4. Time-Series
5. Anomaly Detect
6. Bayesian Fusion
7. Meta-Learner
An Agreement Bar visually maps the percentage consensus across all active layers.

#### EMA Compliance Grid
Direct integration of Zimbabwe's Environmental Management Agency (EMA) SI 6 of 2007 guidelines.
- Parameters (pH, DO, Turbidity, Heavy Metals, AMD) are evaluated against legal thresholds.
- Status is displayed via an intuitive traffic light system (Green, Yellow, Red dots).
- Produces a cumulative Compliance Score percentage.

#### Predictive Forecasting
A dual-horizon Chart.js line graph driven by the LSTM and ARIMA time-series layers.
- Dropdown toggles between **30-Day Daily** and **Quarterly (90-Day)** forecasts.
- The chart maps the predicted trajectory alongside shaded Upper and Lower Confidence Interval bands.

#### Automated Alert System
An active listener monitors the Anomaly Detection layer. If an isolation forest detects an anomaly (e.g., a sudden AMD spike consistent with a tailings breach) or if multiple EMA red violations are triggered, an animated orange/red alert banner drops from the top of the interface detailing the specific threat.

### 4. Temporal Navigation
The bottom footer contains a timeline scrubbing slider, allowing the user to navigate the platform backward in time through historical data logs, useful for correlating past WQI drops with historical pollution events.
